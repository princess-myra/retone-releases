# Retone for Android, without Google

Retone is a voice training app. The APKs here are its Google-free version:
- no Firebase, no account, no analytics, no crash reports;
- no leaderboard;
- bug reports and feedback go by email to contact@blahajbytes.com.

The Play Store and App Store versions are unchanged.

## Install

- Download the APK from the [latest release](https://github.com/princess-myra/retone-releases/releases/latest), or
- add `https://github.com/princess-myra/retone-releases` to [Obtainium](https://github.com/ImranR98/Obtainium) to get updates.

64-bit ARM phones only.

## Check it's genuine

- Package: `com.blahajbytes.retone.apk`
- Signing certificate SHA-256: `7D:FA:4C:E5:06:3A:20:F0:55:D9:BC:87:AF:6D:7A:E3:06:7D:A5:67:6B:60:8E:51:CE:19:9A:92:0F:0A:52:74`

Each release lists its APK's SHA-256.

Releases up to 1.19.0 were the full version (`com.blahajbytes.retone`). From 1.29.0, releases are the Google-free app, which installs as a separate app.
